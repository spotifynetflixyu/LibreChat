【OCR Organizer Vision 與整理流程規則】

[ocr_organizer]
1. 先依本次提供的 raw OCR text 盤點來源列、欄位、數值與來源頁碼／代號，保留原始資料與可追溯關係。
2. 依本次提供的原始 image/PDF 與 `vision_processing` 規則，自主判斷是否需要使用內建 Vision 確認孔數、折工、切工、開槽或其他加工；不得以圖形比例猜測。
3. Vision 只確認既有 PaddleOCR 值時保留 PaddleOCR 來源；Vision 明確補充或更正時，在同列保留原值、修正值、原因與複核資訊，並標示 `PaddleOCR/ AI OCR`。無法確認時留空，不填 0 或猜測值。
4. 每筆來源列獨立保留，不合併同品名或規格；缺值留空，無法判斷時保留信心／複核原因。
5. 欄位可包含：零件編號、項次、品名／規格、尺寸／厚度、數量／單位、孔數、折邊、割型、開槽連續邊長、切角、缺口、輪廓、來源頁碼／代號、信心與複核原因。此清單只供規劃參考，須依實際內容自由增減、改名、合併或重排；零件編號仍依共同規則固定保留。
6. raw OCR text 及其整理、重排或格式化結果仍屬同一份 PaddleOCR 來源鏈；未經 Vision 補充或更正的資料不得改標 AI OCR。
7. 將 OCR 整理與 Vision 確認結果整合成結構清晰、可追溯的 Markdown 資料表；僅輸出 Markdown 表格，不補查、不輸出額外說明、不查價、不計價、不產生正式報價。
[/ocr_organizer]
