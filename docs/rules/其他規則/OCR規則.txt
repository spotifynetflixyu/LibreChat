【OCR 共同規則】

[ocr_shared]
1. 本共同規則適用所有 OCR / Vision 文字處理與資料整理情境，包括一般 OCR、預處理整理及需要重新檢視原始檔案的情境。
2. 讀取文字或圖面前，先確認圖面與文字方向；有旋轉或傾斜時先轉正，再進行 OCR 文字辨識、資料整理或 Vision 圖面判讀。
3. 需要讀取圖片、掃描／影像 PDF、圖面、截圖或手寫附件的文字與表格時，依可取得的 OCR 文字處理；保留來源列、原始規格、數值與來源頁碼或代號。
4. OCR text 與其重排、合併或格式化結果都須保留原始來源鏈；不得因整理方式改變而省略來源或另造資料。
5. 整理 OCR Markdown 時，先盤點 OCR 實際出現的全部欄位與同義欄位，再依資料內容與後續合併需求自主規劃表格欄位；可增減、改名、合併或重排，不限制欄位名稱、數量或順序。除固定的`類別`與`零件編號`欄位外，不使用預設 schema，也不加入 OCR 未明確出現的資料。
6. 所有 OCR Markdown 表格都必須包含`類別`與`零件編號`欄位；凡來源欄位判定可為「編號」或「代號」時，其值一律預設為零件編號，輸出時全部填入「零件編號」欄位，不得另行保留、新增或輸出「編號」欄位。零件編號僅可填 OCR 或來源訂單列明確出現的值，來源缺值時留空，不得從品名、規格、圖號、頁碼、項次、型號／ERP code 或其他欄位推測或代填。
7. `類別`每列填入一個已判定的類別，只能使用：`鐵板`、`C型鋼`、`方鐵`、`H型鋼`、`T型鋼`、`板/浪板`、`平鐵`、`角鐵`、`鋼筋`、`圓管`、`鐵軌`、`槽鐵`、`I型鋼`、`方管`、`扁方管`、`圓條`、`網`、`格板/隔板`、`其他`。不得填自創值或未明列值；無法確認時留空並標示需人工複核，不得猜測。
8. 文字、數字、符號、尺寸或重量不清時，不以「約、略、大約、約略」等近似詞代替；先依 OCR 的欄位脈絡、相鄰欄列、表頭、單位、重複標示與其他可取得的 OCR／Vision 結果交叉確認。能形成合理候選值時，填入最可信值並在備註標示判斷依據、低信心及人工複核；來源未提供該值或無合理候選值時才留空，不得無依據推測。
9. 明顯 OCR 字元誤判可依欄位脈絡修正，但須在備註保留原辨識值、修正值與原因；operand 或公式結果不清時不得自行補齊。
10. 加工欄位只能保留 OCR text 明確出現的內容；本共同規則不依圖形補推、不做幾何判斷或加工計量。未確認資料留空並標示複核。
