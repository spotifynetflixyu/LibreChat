【OCR 共同規則】

[ocr_shared]
1. 本共同規則適用所有 OCR 文字處理與資料整理情境，包括一般 OCR、預處理整理及需要重新檢視原始檔案的情境。
2. 讀取文字或圖面前，先確認圖面與文字方向；有旋轉或傾斜時先轉正，再進行 OCR 文字辨識、資料整理或 Vision 圖面判讀。
3. 需要讀取圖片、掃描／影像 PDF、圖面、截圖或手寫附件的文字與表格時，依可取得的 OCR 文字處理；保留來源列、原始規格、數值與來源頁碼或代號。
4. raw OCR text 與其重排、合併或格式化結果都須保留原始來源鏈；不得因整理方式改變而省略來源或另造資料。
5. 整理 OCR Markdown 時，先盤點 raw OCR 實際出現的全部欄位與同義欄位，再依資料內容與後續合併需求自主規劃表格欄位；可增減、改名、合併或重排，不限制欄位名稱、數量或順序。除固定的零件編號欄位外，不使用預設 schema，也不加入 raw OCR 未明確出現的資料。
6. 所有 OCR Markdown 表格都必須包含零件編號欄位；僅可填 raw OCR 或來源訂單列明確出現的零件編號，來源缺值時留空，不得從品名、規格、圖號、頁碼、項次、型號／ERP code 或其他欄位推測或代填。
7. 文字、數字、符號、尺寸、厚度、數量或重量不清時，不猜測，不以「約、略、大約、約略」等近似詞代替；欄位留空，並在備註標示候選、低信心或人工複核原因。
8. 明顯 OCR 字元誤判可依欄位脈絡修正，但須在備註保留原辨識值、修正值與原因；operand 或公式結果不清時不得自行補齊。
9. 加工欄位只能保留 raw OCR text 明確出現的內容；本共同規則不依圖形補推、不做幾何判斷或加工計量。未確認資料留空並標示複核。
[/ocr_shared]
