【Steel 報價計算驗證規則】

一、`system_order`逐列計算與驗證

1. 產生`## system_order`時，`單重`與`總數`必須依該列已選 candidate 的`類別`與對應的個別鋼材／加工規則，使用本輪 OpenAI Python 計算。不同類別的計重、計長、計件、刀數、孔數或其他計價量公式不得混用；通用規則不得覆蓋個別類別規則。`system_order`.`總數`必須保留該類別結果的精確、未四捨五入計價量。
2. `總數`依計價種類分行計算：
   - Kg類：依該鋼材類別的計重公式算出全部數量的精確總kg，填入`總數`。
   - M類：依該鋼材類別的長度規則算出全部數量的精確總m，填入`總數`。
   - 件／支類：依該鋼材類別的配料、母材與整件規則得到實際計價件數／支數，填入`總數`。
   - 加工計數類：依該加工類別規則計算孔數、刀數、折數或其他實際計價量，填入`總數`。
   - 個別類別例外：存在專用計價或加成規則時，必須以該類別規則計算`總數`，不得改套上述其他種類。
3. `system_order`.`計價基準`取客戶等級（未提供時預設B=2）；`單價`不是 Python 推導值，只能精確複製同一個最終已選 candidate 中與`計價基準`對應的`tierPrices`價格。`## system_order`必須依來源順序保留唯一且有序的逐列結果；每列至少包含來源列識別、candidate 識別、`類別`、精確`總數`、`計價基準`與對應`單價`。
